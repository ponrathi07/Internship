# Python Internship – Day 1

## Projects

### 1. CalcX – Smart Calculator
A Python-based calculator that performs different mathematical operations.

**Features:**
- Addition, subtraction, multiplication and division.
- Power and square root calculations.
- Percentage calculation.
- Even or odd number checking.
- Prime number checking.
- Calculation history.

### 2. VibeMate – Greeting Bot
A simple interactive chatbot that provides personalized greetings.

**Features:**
- Takes the user's name and age.
- Provides greetings based on the time of day.
- Offers different personality choices.
- Displays motivational quotes.
- Calculates the user's future age.
