# Python Internship – Day 2

## Projects

### 1. StudyBuddy – Student Assistant Chatbot
An interactive console chatbot that responds to users based on keywords.

**Features:**
- Interacts with users through text messages.
- Provides predefined responses using keyword matching.
- Stores conversation history.
- Continues the conversation until the user enters `bye`.

### 2. GradeVision – Student Marks Analyzer
A Python application that analyzes student marks and displays performance details.

**Features:**
- Calculates average marks.
- Finds the highest and lowest marks.
- Displays student grades.
- Checks pass or fail status.
- Identifies the class topper.
